ExperimentsFramework

Every experiment follows the same frame

One primary metric, a few guardrails and a decision rule written before launch.

Hypothesis

If we [change], [metric] moves by [MDE], because [reason].

Unit

The host account, stratified by listings and channels.

Sample size

MDE is the smallest change worth shipping. Alpha 0.05, power 0.80.

Run length

Whole weeks, at least 2. No peeking.

Ramp

1%, 5%, 25%, 50%. A 5% holdout for 90 days.

Kill criteria

A guardrail breached 2 days running, undo above 15%, or a live rule violation.

The frame every experiment follows. Hypothesis, one primary metric, guardrails, decision rule. About 30 seconds.

ExperimentsRollout and guardrails

Rollout moves in stages, guardrails can stop it

Each stage has an owner, a go criterion and the kill criteria.

Stage 0 · Internal and plumbing

1%. Events fire, flags work, kill switch tested.

Stage 1 · Experiment

5% to 50%. Pre-computed sample reached, rule applied.

Stage 2 · Full rollout

100% with a 5% holdout. Holdout on the old behaviour for 90 days.

Stage 3 · Holdout read

Retire flags. Long-run effect read, flags removed.

Design

Hypothesis and variants.

Data

Analysis plan and readout.

Engineering

Flags and the kill switch.

Support

The ticket guardrail.

Four stages, four owners. Guardrails alone are monitored daily and can stop a run early. About 30 seconds.
