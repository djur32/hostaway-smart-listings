“Listing management done well is a competitive advantage” · BRIEF

Hospitable’s own brief says listing management done well is a competitive advantage, and AI makes that real. So the story I’d hand Marketing is simple: your listings, handled, and you still have the last word. Each claim is a screen I built. Your facts live once, and every field says whether it uses the Base, is custom for one channel, exists only on one, like Airbnb’s check-in method, or is set by the channel, like the description Booking.com writes, shown behind a lock that says why. Every tip is written for that channel’s strategy and carries its reason. You choose how much runs on its own, but money and stay rules always ask, even on Autopilot, and every change gets a receipt. I’d promise nothing the product doesn’t do, so the line I’d never use is AI does everything. The name is Marketing’s call. About 45 seconds.

Smart Listings only pays off as a system, not a screen. In the middle is what I built: Shared, which is the Listing base and the Knowledge Hub, with Smart Listings on top. The inner ring is in the prototype: tips and the Base reach Airbnb, Booking.com and Direct, the guest assistant reads the same facts, and results come back as Performance.

The next ring is where the build falls short, and I want to name it. Four lines of work are implied but not built: similar homes for each channel; a deeper Knowledge Hub that knows which messages and tasks use each fact; Performance a host can act on over time; and tips beyond the listing, in the Calendar and the Inbox first, on one tip contract. Import joins here, on the same Base.

The outer ring is later: pricing reads the strategy’s goals, owner statements read the receipts, and typed facts feed the Guidebook, Operations, Devices, Google and the API. How I’d run each line of work is one click away. About 70 seconds.
