# Hostaway · Smart Listings

An independent design concept for Hostaway's property management product: a strategy per channel, tips with a why,
a canvas of the real guest page, experimentation and measurement.

- `deck/` the presentation (code-built, GSAP). `cd deck && npm ci && npm run build`
- `prototype/` the website and app-mode prototype (Vite + React + TS). `cd prototype && npm ci && npm run build`
- `ds/` design tokens. `notion/` page sources for the Notion workspace. `plan/` plan and rules. `tools/` helpers.

Example numbers carry the caption "Sample data".
