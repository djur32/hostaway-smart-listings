# Hostaway · Smart Listings

The project repository for Smart Listings: a strategy per channel, tips with a why, a canvas of the real guest page,
and the experiments that tell us whether it works. It is the shared reference for product, engineering, the design lead
and the design director. The narrative lives in the deck and in the Notion project guide; the prototype is the specification.

- `deck/` the project presentation (code-built, GSAP). `cd deck && npm ci && npm run build`. Press N on any slide to open its Notion page.
- `prototype/` the web and app-mode prototype (Vite + React + TS). `cd prototype && npm ci && npm run build`
- `ds/` design tokens and components. `notion/` Notion page map (`map.json`) and screenshots. `plan/` narrative, rules and experiment spec. `tools/` helpers.

Notion project guide: https://app.notion.com/p/400e18af164580aeb1c1f0393d084a85
